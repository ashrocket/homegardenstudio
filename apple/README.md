# Native Apple workspace

The application is a SwiftUI document app for macOS 26 and iOS/iPadOS 26. The default workspace is a full canvas with collapsed secondary panels. A wide window can keep the feature library beside the map; compact windows use a sheet. The inspector offers keyboard and assistive-technology alternatives to direct manipulation. All local previews use the shared Rust geometry engine.

A `.hgsplan` package contains `project.json`, byte-exact files under `Originals/`, and `Renders/`. A versioned native `manifest.json` retains a stable project identity and concept-image provenance without modifying the Rust schema. Imports never re-encode the original attachment. Packages verify stored attachment SHA-256 filenames and metadata sizes when reopened. Originals are retained when source references are removed so undo remains reversible. Current limits are 40 MB per photo/file, 2 MB per fetched URL response, and 256 MB of combined originals and renders per plan. JSON export carries metadata and layout only; portable plan export carries attachments too. Missing originals produce explicit package warnings. External drops accept up to eight images, PDFs or HTTPS links sequentially; dropping JSON or a plan package never replaces the open plan.

Photos and two-point scale calibration do not establish measured positions. Field measurement records a deliberate user assertion about current values; geometry changes invalidate that evidence in the engine. Local 3D uses simplified parts, including the engine's bounding-box approximation for site structures. It is not photorealistic output or a survey.

The free plan blocks new feature additions above twelve. Existing larger plans remain openable, editable and exportable. `Entitlements` is injectable and backed by verified account state when available. App Store products and prices load from StoreKit; unfinished purchases remain retryable until server acceptance. Account setup uses the verified AppTransaction environment and explicitly configured production/sandbox origins. A missing configuration leaves local work available. Secure account recovery lets the user select a preserved identity without creating or transferring accounts.

The assistant offers deterministic engine checks, runtime-gated Apple Foundation Models, an explicitly entered loopback endpoint/model, and optional provider text assistance with separate upload consent. Vision OCR/classification is local evidence assistance and does not establish species, dimensions or position. No model is downloaded automatically.

Cloud concepts use server-discovered models. Layout/reference images are prepared locally for review. Getting a quote requires explicit image-upload consent, and generation requires a separate approval of the frozen request, destination, expiry and debit. A durable recovery journal preserves the same retry identity across uncertainty. Received PNGs are saved before acknowledgement and may be attached to the stable project identity. Existing document attachments remain viewable/exportable offline. Account deletion performs server deletion, then durable recovery cleanup, then Keychain removal. Optional sponsorship uses only actual eligible inventory and finite credit caps; a sponsorship window never invents spendable balance.

## Build and focused tests

Install Xcode 26, XcodeGen 2.45.4 or later, and the Rust targets `aarch64-apple-darwin`, `x86_64-apple-darwin`, `aarch64-apple-ios`, and `aarch64-apple-ios-sim`. The Simulator target is arm64; Intel Simulator is excluded because the shared XCFramework has no Intel Simulator slice. Run `scripts/apple-verify.sh` from the repository root after reserving the shared native build slot. The script checks disk pressure, builds the Rust XCFramework with one Cargo job, generates the Xcode project, runs the macOS build and unit tests, and builds for iOS Simulator with one Xcode job and one Swift source compilation batch. It fails on any failed stage. It does not archive, sign for distribution, upload, or alter signing accounts.

Generated projects, frameworks and local build outputs are ignored. The project configuration retains the release bundle and team identifiers; verification overrides use local ad-hoc/unsigned signing.

Unit tests cover bridge commands and undo/redo, repeated C-returned strings, source serialization, portable persistence and attachment corruption, length parsing, free-plan limits and retained access, replacement undo, URL metadata parsing, and rejection of photo-only measurement evidence.

## Interaction verification still required

A successful build is only a compilation gate. Exercise direct move, corner resize, rotation, cancellation, library drag/drop, zoom, keyboard nudge/delete/duplicate, field commits, document save/reopen, photo/file imports, and previews on Mac, iPhone and iPad. Check narrow windows, large type, light/dark contrast, VoiceOver, keyboard focus and reduced-effects settings. The canvas uses no decorative animation or transparent material that requires a motion-dependent fallback. Run the design skill's static audit and retain actual native runtime evidence before making a visual-quality claim.
