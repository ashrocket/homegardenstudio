# HomeGardenStudio

**In development.** Native builds are being implemented and tested. TestFlight availability and App Store release have not been verified.

Plan a garden at real dimensions on iPhone, iPad and Mac. Place plants, ponds, fire-pit circles, pergolas, saunas, sheds and bin screens; see them in a plan, an isometric drawing and a 3D view; and, if you choose, ask a cloud model for a photorealistic concept based on your layout.
